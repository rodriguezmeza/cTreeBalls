NAME

       cballs - compute two- and three-point correlation functions

SYNOPSIS

       cballs [parameter-file] [name=value...]

DESCRIPTION

       cballs computes correlation functions for scalar fields, point counts,
       full-sky spin-2 shear, Lyman-alpha forests, and physical three-
       dimensional catalogs.  Available search methods are selected at compile
       time.

       Command-line assignments must not contain spaces around the equals
       sign.  Parameter files use one name/value assignment per line and may
       contain comments.

DISCOVERY

       options=make-info
              Print the Makefile settings, resolved toolchain, precision,
              library, OpenMP, and MPI profile embedded in the executable.

       options=print-options
              Print registered runtime option names, scope, and a short
              description.

       options=print-search-methods
              Print only search methods registered in this executable, with
              geometry, statistics, build switch, and usage notes.

ACTIVE SEARCH METHODS

       The maintained profile enables these families:

       octree-sincos-omp
              Core OpenMP octree method for scalar 2PCF and sine/cosine 3PCF
              multipoles.

       kdtree-2balls-omp, kdtree-2balls-mpi
              Median KD-tree dual-node 2PCF and LogMultipole 3PCF.

       balltree-2balls-omp, balltree-2balls-mpi
              PCA ball-tree dual-node 2PCF and LogMultipole 3PCF.

       octree-2balls-omp, octree-2balls-mpi
              Native-octree dual-node 2PCF and LogMultipole 3PCF.

       octree-shear-sphere-2balls-omp
              Full-sky spin-2 correlation functions over the native octree.

       kdtree-shear-sphere-2balls-omp
              Full-sky spin-2 correlation functions over a median KD tree.

       balltree-shear-sphere-2balls-omp
              Full-sky spin-2 correlation functions over a PCA ball tree.

       lya-*-omp, lya-*-mpi
              Anisotropic, radial, and radial interval-tree forest estimators.
              Run options=print-search-methods for the complete names.

       octree-3pcf-3d-omp, octree-3pcf-3d-mpi
              Physical-3D Legendre multipoles and data/random survey-window
              estimation.

       kdtree-box-omp, neighbor-boxes-omp
              Periodic Cartesian 2PCF methods.

COMMON PARAMETERS

       searchMethod=name
              Select a method printed by options=print-search-methods. Alias:
              search.

       infile=path
              Input catalog. Alias: in.

       infileformat=format
              Catalog format. Alias: infmt. Common values include columns-
              ascii, binary, fits-healpix, gadget, and lya-ascii when their
              input add-ons are enabled.

       iCatalogs=list
              One-based catalog selectors used by auto- and cross-correlation
              methods.

       rootDir=path
              Output directory. Alias: root.

       rminHist=value
              Minimum measured separation.

       rangeN=value
              Maximum measured separation.

       sizeHistN=bins
              Number of radial bins.

       mChebyshev=order
              Largest positive 3PCF multipole order.

       useLogHist=bool
              Choose logarithmic or linear radial bins.

       numberThreads=count
              OpenMP threads per process or per MPI rank.

       options=list
              Comma-separated behavior controls.

SEARCH CONTROLS

       only-2pcf, only-3pcf
              Run only the requested compiled correlation order.

       no-two-balls
              Disable dual-node cell aggregation and use the exact body-pair
              limit.

       dual-node-bin-slop
              Enable bin-position-aware Log/Linear node acceptance.

       no-smooth-pivot
              Disable the build-default pivot smoothing on methods that
              support it.

       read-mask
              Apply a supported companion or in-memory binary mask.

       edge-corrections,no-normalize-HistZeta
              Compute complex scalar or shear 3PCF window correction. This
              requires 3PCF.

       weights-norm
              Use catalog weights in signal and normalization moments.

PYTHON

       The compiled extension is imported as cyballs.  The convergence, shear,
       and forest drivers are under tests/python.  They retain one NumPy
       catalog across selected engines and write timing and comparison
       summaries.

MPI

       Use one MPI implementation for MPICC, the runtime launcher, the
       extension, and mpi4py. numberThreads is per rank. All ranks enter the
       same run and cleanup sequence; rank zero writes results.

EXAMPLES

       Inspect the executable:

         cballs options=make-info
         cballs options=print-options
         cballs options=print-search-methods

       Run a scalar angular 2PCF:

         cballs search=octree-2balls-omp infile=catalog.fits     infmt=fits-healpix options=only-2pcf rootDir=Output

       Run masked edge-corrected 3PCF:

         cballs search=kdtree-2balls-omp infile=map.fits,mask.fits     infmt=fits-healpix,fits-healpix     options=read-mask,only-3pcf,edge-corrections,no-normalize-HistZeta     rootDir=Output_edge

       Run an MPI forest estimator:

         mpiexec -n 2 cballs addons/lya_forest_mpi/parameters.ini
